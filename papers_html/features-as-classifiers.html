用字典学习特征作为分类器

Using dictionary learning features as classifiers · Oct 16, 2024 · Interpretability · 查看原文

📖 中文摘要

这是Anthropic可解释性团队的工作进展报告，探索能否用字典学习从大模型内部提取的可解释特征来训练分类器，用于检测模型是否被提示了与生物武器相关的有害信息。初步结果显示：基于特征激活的线性分类器可媲美甚至超越基于原始激活的分类器；决策树分类器更可解释但性能较低；可视化线性特征分类器有助于发现数据集中的虚假相关性，这些虚假相关性还可转化为有效的对抗攻击。不过原始激活仍是强基线，使用特征会引入显著复杂性，实际应用需在性能与特征带来的独特优势间权衡。

专业术语注解

分类器：判断输入属于哪一类的机器学习模型特征激活：模型内部代表某概念的那些神经活动的强度字典学习：把神经活动分解为可解释基本特征的技术虚假相关性：数据集中看似相关、实则偶然或误导性的关联对抗攻击：精心构造输入以欺骗AI模型的方法基线：用作对照的基准方法，用于评估新方法是否更优
