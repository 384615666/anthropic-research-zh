## **引言**
一年前，大多数 Claude 的使用形式是用户与助手之间的一次对话。随着 Claude Code 和 Cowork 的快速增长，Claude 会话如今越来越多地由长时间运行的智能体任务构成。聊天记录已无法完全反映人们如何使用 AI，我们研究 Claude 经济影响的方法也不得不随之调整。
为了跟上这一变化，我们对经济指数的数据管道进行了几项修改。在本版本中，我们：
  * 以更高的频率采样数据，使我们能够观察到小时级别的使用模式。
  * 引入一个新的分类器，为每次对话的输出打标签。
  * 分享更细粒度的数据，将聊天（chat）与 Cowork 对话（合称「Claude 对话」）以及第一方 API（1P API）的结果分开呈现，并按月聚合。¹

我们在[附录](<https://cdn.sanity.io/files/4zrzovbb/website/03ed1410f74a65ae4cc2a27120d0875e1e569535.pdf>)中描述了其他方法上的调整。这些调整共同描绘出一幅更清晰的图景，展示 AI 如何映照并渗透进经济生活。
此外，我们此前一直无法观察到 Claude 在用户会话_之外_的影响。人们如何看待 AI 正在改变他们的工作或他们可获得的机会？使用 AI 是否塑造了他们的预期？在理想情况下，他们希望 AI 提供什么？我们在此报告自 2026 年 4 月启动的 [Anthropic 经济指数调查](<https://www.anthropic.com/research/economic-index-survey-announcement>)的初步发现。
我们在下方预览主要发现。
  * 在第 1 章中，我们展示外部世界的节奏如何塑造 Claude 的使用。与工作相关的查询在周末减少，但在收入最高的职业中降幅不那么明显；人们倾向于在早上询问新闻，睡眠建议的请求在凌晨 5 点左右达到高峰；报税相关请求在申报截止日期前后激增。

  * 第 2 章探讨人们从 Claude 会话中获得的具体产出。这些产出高度依赖他们使用的产品。例如，聊天和 Cowork 提供的解释比 Claude Code 更多。产出的性质也塑造了人们与 Claude 的互动方式。构建网站比翻译文档留给 Claude 更多判断空间——翻译的答案在很大程度上由文本本身决定。我们还发现，更多的算力与更有价值的产出相关；某个产出所消耗的 token 数量随该工作价值的估计值上升。

  * 第 3 章呈现 Anthropic 经济指数调查的首批结果，我们通过[隐私保护系统](<https://www.anthropic.com/research/clio>)将其与 Claude 使用数据关联起来。预期和体验随人们使用 Claude 的方式而系统性变化：以最自动化方式使用 Claude 的人预期 AI 将在未来一年承担更多他们的任务，但同时对这对其工作意味着什么感到最为乐观，预期在薪酬、工作保障和工作意义上都会产生积极影响。

## **节奏**
我们新的隐私保护遥测系统每天持续采样一部分对话，使我们能够研究使用中的日间和小时模式——而此前每期经济指数报告依赖的都是七天样本。这些分析捕捉到了世界各地工作节奏的起伏。²
我们发现 Claude 的使用与工作周同步，个人类提示词在周末飙升。小时级数据捕捉到了日内模式——人们最常在凌晨 5 点左右询问睡眠建议，在下午 6 点左右询问食谱。我们还看到使用情况反映关键日期。例如，报税相关请求在 4 月 15 日美国申报截止日期之前激增。
### 工作周
在样本期内，被归类为个人使用的聊天和 Cowork³ 对话占比从工作日的约 35% 上升到周末的接近 50%（图 1.1）。在工作周之外，用户的对话从商务函件、营销文案和幻灯片转向情感支持、医疗问题和投资建议。这种转变在高收入国家最为明显。
![](assets/economic-index-june-2026-report/img_001.img)**_图 1.1：个人对话在周末增加  
_ **_每日个人使用对话占比，覆盖 [Claude.ai](<http://claude.ai>)、Claude 桌面版、Claude Code 和第一方 API（1P API）。周六和周日以灰色阴影标示。_  

  
Claude Code 和第一方 API 流量（即直接通过 Anthropic 路由的 API 流量）中也存在类似的模式，不过两者的个人使用基线占比都较低。⁴
请求簇（request clusters）⁵ 让我们能够再深入一层，看到哪些具体的 Claude Code 任务在周末与工作日之间波动最大。在周末，占比下降最多的 Claude Code 使用簇包括后端架构、API 调试和数据存储。占比上升最多的包括 AI 智能体设计、量化交易和游戏。
周末也可能为人们开辟探索新事业的空间。在各国中，与创业相关的对话在周六和周日最高。然而，求职申请活动与其他工作相关任务一样在周末下降。⁶
###   
每日节奏
逐小时来看，Claude 的使用反映了日常生活的节奏。图 1.2 显示了不同请求簇相对于其在全球流量中总体均值的小时频率。⁷
人们在当地时间早上 7 点询问新闻。商务函件（如起草电子邮件）沿着工作日的轨迹起伏，在上午 10–11 点略有高峰。最大的峰值之一是食谱请求，其下午 6 点的频率是平均水平的 2.3 倍。媒体推荐最集中在晚间，而人们在天亮前的几个小时里寻求睡眠建议。

在夜间和周末，当人们确实转向 Claude 处理工作时，任务倾向于偏向高薪职业（图 1.3）。虽然我们无法确切识别这些请求者的职业，但这可能反映出高薪职业人群——如营销经理或计算机程序员——更可能在传统工作时间之外工作。相比之下，与收入最低两个四分位职业（如电话推销和文书工作）相关的任务在总对话中的占比下降。这种模式并非仅由计算机和数学类任务驱动：在稳健性检验中，当我们把这些职业从分析中移除后，较高四分位的任务在夜间和周末仍然增加。

## 产出
在本章中，我们按产出（artifact）对聊天和 Cowork（以下简称「Claude 对话」）⁸ 中的每次对话进行分类，将其归入 30 多个类别。我们把 Claude 在对话中产生的主要输出——一份文档、一段解释、一段代码、一篇学术论文等，无论是在聊天窗口中呈现还是作为独立文档——称为产出。完整的产出列表见[附录](<https://cdn.sanity.io/files/4zrzovbb/website/03ed1410f74a65ae4cc2a27120d0875e1e569535.pdf>)。
我们的分类器识别出 93% 的 Claude 对话产生了某种产出（图 2.1）。⁹ 最常见的产出是解释（占对话的 17%）、文档和报告（15%）以及指导建议（11%）。对话式产出（如解释或指导建议）和书面交付物（如文档或演示文稿）各占对话的约三分之一；代码和技术性工作（如应用或脚本）约占六分之一。
  

![](assets/economic-index-june-2026-report/img_005.img)**_图 2.1：Claude 的输出  
_ **_具有特定输出的对话占比。该图展示 Claude 对话中十二种最常见的输出类型。第一方 API 的构成见附录。_  

  
产出是什么并不能告诉你它的用途：同一个产出可能是工作交付物，也可能是个人项目。我们接下来考察这一区分。
###   
每种产出用于什么目的？
我们的[一月经济指数报告](<https://www.anthropic.com/research/anthropic-economic-index-january-2026-report>)引入了一种将每次对话分类为工作、个人或课程作业的原始方法。在这里，我们将这一区分应用于 Claude 对话中产生的产出（图 2.2）。
有些产出类别几乎总是个人用途。超过 80% 的创意写作、指导建议和食谱对话被归类为个人用途。在各类别内部，个人用途与工作相关用途可能差别很大。例如，个人创意写作以同人小说、世界观构建和诗歌为主；其中 13% 的工作相关写作主要是短视频脚本、编剧和演讲稿形式。最可能属于工作相关的类别包括创建营销内容（80%）、撰写博客或文章（81%）和编写数据库查询（82%）。
许多产出用于个人和工作目的的可能性相当，包括制定计划或策略（44% 工作相关，49% 个人）或翻译（42% 工作，44% 个人）。例如，最常见的个人规划类产出包括旅行行程和健身计划，而工作相关计划则最多涉及创业或内容策略。
最后，课程作业特征的产出包括撰写学术论文和学位论文、制作教育材料以及与数学相关的查询，不过每一类都有相当一部分同时落入工作和个人两类。
![](assets/economic-index-june-2026-report/img_006.img)**_图 2.2：按用途划分的产出占比  
_ **_具有特定输出的对话占比，按用途分类为工作、个人和课程作业。_  

  
我们也可以反转这个问题。与其问每种产出用于什么，不如问工作、个人和课程作业对话各自倾向于产生什么类型的产出。工作对话最常产生文档和报告（20%），其次是解释（9%）、电子邮件草稿（7%）以及分析和摘要（6%）。课程作业对话总体相似，文档和报告同样居首（21%），紧随其后的是解释（20%）、教育材料（11%）和学术论文（6%）。相比之下——毫不意外——个人对话中只有 6% 产生文档。相反，最常见的结果是解释（25%）和推荐（22%）。  
  

### 成本与工作价值挂钩   

产生这些产出需要算力，我们发现算力往往随工作价值增长而增长。我们以 token——即处理和生成的文本量，包括 Claude 的内部推理——来衡量每次对话的计算成本，并通过将每次对话的分类任务映射到通常执行该任务的职业来跨职业比较。在本节中，我们将分析限定于工作相关对话。
  
图 2.3 左面板显示对话级 token 数中位数与映射职业工资中位数之间的正相关关系。¹⁰ 例如，营销经理的薪酬大约是编辑的两倍（时薪 80 美元 vs. 37 美元），而映射到他们任务的对话消耗的 token 数约为后者的 2.5 倍。诚然，这种关系存在噪声，也有显著离群值。例如，药剂师的收入接近统计助理的三倍（时薪 68 美元 vs. 24 美元），但映射到药剂师任务的对话消耗的 token 数仅为后者的约二十分之一。
![](assets/economic-index-june-2026-report/img_007.img)**_图 2.3：高薪职业的对话消耗更多 token  
_ **_左面板：特定职业的工资中位数与分类到该职业某项任务的对话中典型（几何均值）token 数之间的关系，已按总体均值归一化。两个变量均以对数刻度表示。右面板：生成特定产出所用 token 的分布。黑线表示中位数，箱体表示第 25 和第 75 百分位，须线表示第 10 和第 90 百分位。所有数字均按总体 token 中位数归一化并以对数刻度呈现。两个面板的数据均限于聊天和 Cowork，且限于被分类为工作相关的对话。token 计数未针对服务该对话的模型进行调整。_  

生成不同类型产出所消耗的 token 讲述着类似的故事。更复杂、更有价值的输出往往比更简单的输出消耗显著更多的 token。例如，关于构建应用的对话使用的 token 数超过中位数对话的三倍。在光谱的另一端，一次典型的解释使用的 token 数约为中位数对话的五分之一。token 消耗中工资梯度的约 44% 可由产出构成解释——高薪职业更有可能产生算力密集型产出。
这在经济上为何重要？在映射到高薪职业的对话中，Claude 产出更多（每轮产出量为 1.34 倍），用户参与更多（轮数为 1.53 倍），并且更频繁地启用扩展思考（34% 的对话 vs. 31%；表 2.4）。关键在于，这些是同步变动的：Claude 产出更多并不意味着用户产出更少。如果人类仍然参与最高价值的任务，这种模式看起来更像是劳动增强而非劳动替代。它还表明，在某种程度上，更有价值的产出成本更高。下一节将考察每次对话中有多少决策被委托给了 Claude。
![](assets/economic-index-june-2026-report/img_008.img)**_表 2.4：高薪职业中更高 token 消耗的来源  
_ **_导致映射到高薪职业的对话中 token 消耗更高的对话特征。职业按工资中位数分为三等分，并以匹配到各职业的对话数量加权。算力相关指标按最低三等分的几何均值归一化。例如，第一行显示映射到最高三等分职业的典型对话消耗的 token 数是映射到最低三等分职业的典型对话的 2.07 倍。_  

### Claude 能多大程度上自主决策？
我们以 1–5 的等级来衡量这一点，从「无」到「极高」。易于描述或指定的任务涉及很少的自主性：自主性最低的输出是数学或计算、翻译和问答。高自主性任务是那些需要在众多可能选择中做出挑选的任务，例如创建应用和网站、游戏或演示文稿。这类需要持续判断的工作历来难以自动化。通过比较 Claude 聊天和 Cowork 与 Claude Code 的自主性水平，我们表明这种情况正在开始改变。
在几乎所有类型的输出中（所展示的 31 种输出中的 26 种），Claude Code 上的 AI 自主性水平都高于聊天或 Cowork。¹¹ 例如，产生脚本和代码片段的对话在使用 Claude Code 时，其自主性平均比在聊天或 Cowork 上产生相同输出的对话高 0.53 分（在 1–5 等级上）。在所有对话中，自主性的平均差异为 0.37 分，其来源主要有两个。¹²
约三分之二的差异可以用同一任务在 Claude Code 上以更高程度的委托执行来解释。博客文章即为例证：两个平台上其背后的请求和任务相似，但人们与 Claude 协作的方式截然不同。产生博客文章或文章的聊天和 Cowork 对话中位数涉及 13 轮来回交流，而产生博客的 Claude Code 会话中位数仅包含一条人类提示词。剩余的三分之一反映两个平台上输出类型的构成不同。
  

![](assets/economic-index-june-2026-report/img_009.img)**_图 2.5：_ 按输出类型划分的 AI 自主性  
**各对话输出和平台的 AI 自主性平均水平。AI 自主性按 1–5 级评定，从「无」到「极高」。
有人可能怀疑这一差异只是反映了模型选择。Claude Code 会话运行在最强大模型上的频率要高得多（54% 由 Opus 提供服务，而聊天和 Cowork 对话仅为 10%）。然而，当我们比较由同一模型服务的对话时，这一差距依然存在。例如，在使用 Sonnet 的对话中，Claude Code 会话的自主性仍然高出 0.26 分，这表明所使用的产品可能比底层模型更重要。
跳出平台比较来看，用户委托程度最高的输出类型也正是消耗算力最多的类型：在各产出之间，平均自主性与 token 使用中位数同步上升（聊天和 Cowork 上 r = 0.68；[附录](<https://cdn.sanity.io/files/4zrzovbb/website/03ed1410f74a65ae4cc2a27120d0875e1e569535.pdf>)图 A.2）。
### Claude 的回答水平高于提问水平
对于每次对话，分类器会估算两个阅读水平——一个是用户提示词的水平，一个是 Claude 回应的水平——用理解该文本所需的教育年限来表示。¹³ 我们发现阅读水平因产出类型而异。产生学术论文的平均查询需要超过 16 年的教育年限，大致相当于本科水平，其中 15% 的对话达到博士水平或以上（20 年或更多教育年限）。在光谱的另一端是产生食谱或指导建议的对话，理解其提示词所需的受教育年限不到 10 年。
总体而言，输出阅读水平较高的产出类型，其提示词阅读水平也较高（跨对话相关系数为 0.87）。然而，我们也观察到，在几乎所有类别中，Claude 输出的理解水平都高于提示词，平均高出约一年受教育年限。在用户描述要构建的内容时差距最大，如图像和图形（+2.6 年）、游戏（+1.9）以及应用和网站（+1.7）。部分差距可能只是语域差异；提示词往往简短随意，而 Claude 倾向于以精炼的散文回应。然而，对于面向受众的写作（博客 −0.1、学术论文 +0.0、电子邮件 +0.3），差距接近于零，这可能是因为这些提示词通常起草的是与预期输出相同语域的语言或源材料。

## **感知**
前两章展示了人们如何使用 Claude，但未深入揭示人们在工作中体验 AI 的方式——他们预期自己的工作和职场将如何变化、他们对 AI 当前和潜在影响的感受，以及他们对这项技术的期望。我们于 2025 年 12 月使用 [Anthropic Interviewer](<https://www.anthropic.com/research/anthropic-interviewer>) 对 [81,000 名 Claude 用户的访谈](<https://www.anthropic.com/features/81k-interviews>) [描绘了一幅图景](<https://www.anthropic.com/research/81k-economics>)：受访者报告了巨大的生产力提升，但也表达了对替代的担忧。这些担忧集中在职业生涯早期的员工以及我们观察到 Claude 承担最多工作的职业。¹⁴
2026 年 4 月，我们启动了 [Anthropic 经济指数调查](<https://www.anthropic.com/research/economic-index-survey-announcement>)，以在此基础上继续推进。该调查使我们能够直接询问人们关于 AI 与工作的体验，并探索回答如何随 Claude 使用情况而变化。我们使用[隐私保护方法](<https://www.anthropic.com/research/clio>)将调查回答与 5 月中旬至 6 月初的使用数据关联起来。为刻画每位受访者的使用模式，我们在此时间窗口内随机抽取每人最多 20 个会话（覆盖 Claude.ai、Cowork 和 Claude Code，使会话构成反映每个人跨平台的典型使用情况）。我们剔除会话数少于五个的受访者以减少抽样噪声。最终关联样本包含约 9,700 名调查受访者。
我们发现大多数受访者预期 AI 将在未来一年取得显著进步。虽然人们对 AI 能力的感知取决于他们的经验、居住地以及其工作暴露于 AI 的程度，但他们对于未来进步速度的预期却惊人地一致，这与「[水涨船高](<https://arxiv.org/abs/2604.01363>)」的图景相符，即 AI 能力全面改善。
对于这种进步对其自身职业意味着什么，看法则不那么一致。职业生涯早期的员工报告说 AI 能完成他们工作中最高比例的部分，并对失业表达最多的担忧。然而——与一种常见担忧相反——向 Claude 委托最多的人对自身未来劳动力市场结果_最为_乐观，并感到自己的技能价值在增长。而且，尽管（或许正因为）接近 AI 的前沿，受访者对未来十年的平均期望并非替代，而是协作。他们希望 AI 能保留有意义的工作、自动化琐碎的苦差事，并希望 AI 带来的收益能被广泛分享。
### **谁回应了经济指数调查**
经济指数调查并不代表总体人口。我们覆盖的是 Claude 用户的随机样本，谁完成调查可能存在选择性，而且我们在分析中过滤掉了不常使用的用户。图 3.1 显示了调查受访者的职业构成（橙色）以及美国就业人口（灰色）。计算机和数学类职业的代表性过高最为严重，约占受访者的 30%——与其在 Claude 使用中的占比相当，但远高于其在美国就业人口中 4% 的占比。管理层占受访者的 23%，¹⁵ 相对于其 7% 的就业占比也严重偏高，尽管它只占会话的 4%。这一差距与管理层将 Claude 用于管理本身以外的任务一致：在调查中，判断力和管理被许多受访者（尤其是经验更丰富的受访者）列为 AI 所缺乏的能力。交通运输及物料搬运、食品制备及餐饮服务相关、建筑及开采等体力职业类别在调查中的代表性不足，在 Claude 会话中也是如此。
  

![](assets/economic-index-june-2026-report/img_011.img)**图 3.1：_与美国的就业结构相比，调查受访者严重偏向计算机与数学以及管理类职业  
_ **_在 22 个主要 SOC 职业组¹⁶ 中报告其职业的受访者占比，与来自 OEWS 的各职业在美国就业人口中的占比对比。_  

### **AI 与工作任务**
关于 AI 影响的研究往往聚焦于职业暴露度（occupational exposure），即某一特定工作中的任务有多大比例可以用 AI 完成。在[先前的工作](<https://www.anthropic.com/research/labor-market-impacts>)中，我们构建了一个_观测暴露度_指标，捕捉我们已经看到由 Claude 完成的职业任务占比。我们将其与一种常用的[_理论暴露度_](<https://arxiv.org/abs/2303.10130>)指标（即大语言模型理论上能完成的职业任务占比）进行了比较。
理解职业暴露度的另一种方式是直接询问人们 AI 能完成他们工作的多大比例。我们询问受访者，AI 今天能完全独立完成他们多大比例的工作任务（以下称为_报告暴露度_），以及他们预期 12 个月后这一比例会是多少（_预期暴露度_），并提供从「几乎没有」到「几乎所有」的五个区间供选择。近六成受访者对未来一年的选择高于当下。超过三分之一的人预期明年 AI 能完成他们大部分或几乎全部工作任务（图 3.2）。
  

![](assets/economic-index-june-2026-report/img_012.img)**图 3.2：_大多数受访者预期 AI 能完成的工作任务占比将在未来 12 个月内增长  
_ **_该图展示了受访者所说 AI 今天与 12 个月后能完成的工作任务占比分布。_  

图 3.3 将报告暴露度和预期暴露度与观测暴露度和理论暴露度进行比较。我们考察：人们报告和预期的 AI 能力是否与跨职业的观测暴露度和理论暴露度指标一致，以及职业在观测或理论暴露度上得分较高的受访者是否预期来年进步更快。对于第一个问题，答案是肯定的：报告暴露度（灰点）与观测暴露度和理论暴露度均呈正相关。对于第二个问题，答案是否定的：报告暴露度和 12 个月后预期暴露度的最佳拟合线（橙点）基本平行，这意味着观测或理论暴露度高的岗位从业者与暴露度较低的岗位从业者，对来年 AI 能完成其工作任务占比的_增幅_预期大致相同。¹⁷ 换言之，软件工程师和建筑经理预期各自职业领域内会有大致相同的进步幅度。
同样值得注意的是，报告暴露度系统地高于观测暴露度。一种解释是，并非每个人都执行某个职业中的所有任务，而我们的调查不成比例地触达了更多使用 AI 的人。¹⁸ 类似地，由于理论暴露度是可能性的上限而非当前使用情况的度量，理论暴露度系统性地高估了报告暴露度。
  

![](assets/economic-index-june-2026-report/img_013.img)**图 3.3：_报告暴露度和预期暴露度与其他指标的对比  
_ **_人们所说 AI 今天能完成的任务占比（报告暴露度，灰色）和 12 个月后能完成的占比（预期暴露度，橙色），分别与观测暴露度（左面板）和理论暴露度（右面板）对照。每个点代表一个职业，样本量较小的职业与暴露度相近的职业合并以保证隐私。报告暴露度和预期暴露度按受访者所选区间的中点计算。_  

我们还考察了对 AI 当前和未来能力的感知如何与受访者的特征和使用模式相关。图 3.4 左面板显示，对 AI 能力的感知与国家 GDP 呈负相关：¹⁹ 高收入国家的人们报告 AI 现在能为其完成的任务平均占比大约低 10 个百分点。这一模式与以下可能性一致：即使职业级暴露度指标（在发达经济体往往更高）暗示相反，AI 在低收入国家工人日常执行的更大比例任务上充当了替代品。事实上，[IMF 曾指出](<https://www.imf.org/-/media/files/publications/sdn/2024/english/sdnea2024001.pdf>)，虽然发达经济体总体上面临更广泛的 AI 暴露，但低收入国家的工人可能更难获得让 AI 增强而非替代其工作的互补技能和基础设施。在[更早的工作](<https://www-cdn.anthropic.com/7b76335c444876a93fa22a63aabb4aeb820aff25.pdf>)中，我们记录到即使对任务构成的差异进行调整，低收入经济体也倾向于以更自动化的方式使用 Claude。
中间面板显示，报告暴露度和预期暴露度也与工作年限呈负相关。²⁰ 至少有 15 年经验的人所报告的 AI 能完成的任务占比，比工作第一年的人低约 10 个百分点。我们发现证据表明，这可能是因为经验丰富的工人积累了难以被 AI 模仿的隐性或情境特定专业知识。在后续问题中，我们询问人们他们认为 AI 永远无法完成什么任务及其原因；最常见的回答强调，AI 缺乏其工作所需的判断力、情境意识和情境推理。受访者——尤其是那些至少有 15 年经验的受访者——还指出其工作的关系性和人际维度——建立信任和管理人员——是 AI 无法复制的。
与职业对 AI 的暴露度一样，我们发现对未来 AI 能力提升的感知与人均 GDP 和工作年限基本不相关。对 12 个月后 AI 能完成的任务占比的预期一致地高于对 AI 当前能力的感知。
  

![](assets/economic-index-june-2026-report/img_014.img)**图 3.4：_报告暴露度和预期暴露度在高 GDP 国家和经验更丰富的工人中更低，并随自动化 Claude 使用增加而上升  
_ **_报告暴露度和预期（12 个月）暴露度，分别对照国家人均工作年龄成年人 GDP（左）、工作年限（中）和被分类为自动化的 Claude 会话占比（右）。_  

接下来我们考察人们与 Claude 的互动方式与其当前对 Claude 能力的感知之间的关系。与以往报告一样，我们区分与 Claude 协作的「自动化」和「增强」两种模式。当 Claude 被要求以很少或没有用户输入的方式完成任务时，我们将对话识别为自动化。具体而言，自动化占比是指其模式为「指令式」（如「翻译这份文档」）或「反馈循环」（如「修改这封电子邮件……让它更随意些」）的对话占比。²¹
图 3.4 右面板显示，报告暴露度和预期暴露度随自动化占比上升。这可能是因为委托本身就传递了能力信息——将整个任务交给 AI 的人能直接观察到 AI 能独立完成什么——也可能是因为那些已经相信 AI 能完成其工作的人最愿意将其交出。当我们用工作相关任务会话占比或 Claude Code 会话占比替代自动化占比时，模式保持不变。²²
### **AI 与就业**
我们还询问人们认为自己的工作在未来 12 个月将如何变化。超过三分之一的受访者表示，职责发生重大变化的可能性为「可能」或「很可能」（针对他们自己、同级同事、初级同事和高级同事分别作答）。10% 的人认为自己失业的可能性为「可能」或「很可能」。这略低于美国失去工作的年化风险率；²³ 然而，由于我们的受访者偏向稳定就业的知识工作者（这一群体在基准水平上面临的离职风险可能低于平均水平），这可能仍表明感知风险升高。当被问及是什么驱动了他们的预测这一开放式问题时，在认为自己失业可能或很可能的受访者中，38% 将其预测归因于 AI。²⁴ 值得注意的是，受访者平均对他人失业的担忧超过对自己失业的担忧。²⁵ 受访者尤其担心初级同事失业，超过三分之一的人表示初级同事在未来一年内失业的概率超过 60%。受访者对低收入国家（所有人）的失业也更为担忧。
  

![](assets/economic-index-june-2026-report/img_015.img)**图 3.5：_报告工作职责将发生重大变化或人们将非自愿失业的可能性为「可能」或「很可能」的人群占比  
_ **_报告工作职责可能发生变化（左面板）或某人可能失去其想保住的工作（右面板）的受访者占比，分别针对自己、同级同事、初级同事或高级同事。_  

以更自动化方式使用 Claude 的人是否也更担心失去工作？我们考察人们关于 AI 在未来一年对工作六个维度的预期影响的说法：薪酬、工作保障、找到新工作的能力（经济维度）以及意义感、自主性和人际互动（内在维度）；并研究这些预期如何随 Claude 使用的自动化占比而变化。
在所有六个维度上，自动化会话占比更高的人，对 AI 明年对其工作结果的影响感觉_更乐观_，相比以更增强方式使用 Claude 的人。我们在对未来薪酬和找到工作能力的积极影响预期上看到了最大的效应。²⁶
  

![](assets/economic-index-june-2026-report/img_016.img)**图 3.6：_在自动化程度更高的 Claude 用户中，报告 AI 对工作质量的经济和内在维度产生积极预期影响的人群占比更高  
_ **_该图展示了对「人们是否预期 AI 对工作质量的六个维度产生积极影响」这一指标进行线性回归所得的系数估计值，自变量为归一化的 AI 自动化占比。_  

一个自然而然的问题是，为什么自动化使用与情绪会同步变动。这种关系有可能由选择性解释：对 AI 最热衷的人也最愿意把整个任务交给它。我们不能完全排除这一点，但当我们控制了用户在 [Claude.ai](<http://claude.ai/redirect/website.v1.a9148b62-0651-4fcd-ae19-1926306aa8d5>) 上的使用时长——我们可以将其视为热情程度的代理，因为它区分了早期与较晚期的采用者——这些估计值没有发生有意义的改变。
另一种可能是，以更自动化方式使用 AI 的人今天就能体验到更多它的好处。与我们的[先前发现](<https://www.anthropic.com/research/81k-economics>)一致，绝大多数人报告在工作的速度、范围和质量方面获得了生产力提升（分别为 86%、82% 和 69%），而 27% 的人报告通过节省原本需要购买的服务成本获得收益。
除了显著的生产力提升，大多数人还报告通过 AI 学到了更多（68%），并觉得 AI 让他们的技能变得更有价值（57%）。图 3.7 显示了这两个结果如何随自动化会话占比变化。我们看到，报告 AI 正在提高其技能市场价值的人群占比随自动化占比上升，而报告自己学到更多的人占比大致持平。
关于委托，一个常见的担忧是把整个任务交给 AI 意味着外包思考，产出的增加以学习和技能退化为代价。我们在这里没有看到这种模式：委托更多的人也报告与其他所有人相同的学习率。然而，这些都是自我评估，而且技能即使在变得更有价值、即使有人报告学到更多的情况下也可能退化，因此数据并不能排除技能退化。
  

![](assets/economic-index-june-2026-report/img_017.img)**图 3.7：_报告技能获得积极预期回报的人群占比随自动化占比上升，而报告学到更多的人占比持平  
_ **_该图展示了任务自动化占比与报告 AI 提高其技能市场价值的人群占比（蓝色）以及使用 AI 时学到更多的人占比（橙色）之间的关系。_
### **不同性别之间的使用差异**
到目前为止，我们探讨了使用模式与预期和行为之间的关系。接下来，我们研究_谁_在以各种方式使用 Claude。最显著的差异是按性别划分的。女性仅占我们关联受访者样本的 12%，她们使用 Claude 的方式与男性不同。即使在考虑职业差异之后，她们使用 Claude 处理工作的可能性也略低，她们在 Claude Code 中的会话占比低 0.24 个标准差（6.3 个百分点），自动化占比低 0.33 个标准差（7.3 个百分点）。相反，女性倾向于更迭代地使用 Claude，她们在聊天上的活跃时间比男性更长，这是更协作式参与的信号。²⁷  

![](assets/economic-index-june-2026-report/img_018.img)**图 3.8：_即使在控制职业差异后，女性也有明显不同的使用模式  
_ **_该图展示了女性与男性相比的使用模式。每根柱状图是女性与男性在该使用指标上的平均值之差，控制职业（SOC 子组）后，以结果的标准差表示。须线显示 95% 置信区间。样本限于自我认同为女性或男性的受访者。女性的 Claude Code 和自动化占比显著更低，而总活跃分钟数更高。_  

  

### **人们对 AI 转型后的经济有何期望？**
Anthropic 经济指数调查呈现了人们对 AI 积极与消极体验和情绪的交织，但我们以充满希望的方式结束调查。最后一个开放式问题要求受访者「大胆想象：你希望十年后一个由 AI 塑造的经济是什么样子？」我们让分类器对每份调查回答进行标记，标出相关的主题。下面展示最常被提及的前五大主题。每个主题的更多描述见[附录](<https://cdn.sanity.io/files/4zrzovbb/website/03ed1410f74a65ae4cc2a27120d0875e1e569535.pdf>)。
  

![](assets/economic-index-june-2026-report/img_019.img)**图 3.9：_人们期望人机协作、琐事自动化和更多自由时间，以及 AI 带来的经济收益被广泛分享  
_ **_该图展示了人们对「你希望十年后一个由 AI 转型的经济是什么样子」这一开放式问题回答中最常见的五大主题。_
最常被表达的主题是 AI 对工作的_增强_。超过一半的受访者表达了某种形式的愿望：与 AI 协作完成有意义的工作、希望自己的职业仍然重要，以及/或者希望出现新产业并创造新的就业机会。与此同时，略超过一半的受访者希望 AI 实现_自动化_——具体来说是自动化他们工作中枯燥的部分——以便他们有更多自由时间和更多工作之外的意义空间。第三常见的主题由约三分之一的受访者表达，是共享繁荣：希望 AI 带来的经济收益被广泛分享。
##   
**讨论**
AI 正在迅速扩散到整个经济中，覆盖越来越多的平台，产出越来越智能。在早期的 AI 聊天界面中，使用很简单，局限于聊天窗口内，没有网络搜索、工具调用、产出或其他功能。如今，Claude 模型可以通过 Claude Code 和 Cowork 自主运行数小时。随着这些形式的变化，用户群体也在转变。早期采用者高度技术化。我们最新的用户将 Claude 应用于劳动力市场上[工资较低](<https://www.anthropic.com/research/economic-index-march-2026-report>)的任务。
在本报告中，我们采取了几个步骤来推动更具信息量的度量。首先，我们开始以越来越高的频率进行测量，按小时样本处理数据。这揭示了日常生活的节奏如何刻印在我们的使用日志中，并为未来的研究开辟了途径。其次，我们开始记录产出，即人们从 Claude 获得的结果。这使 Claude 的工作输出更加清晰可读，并呈现出一些直观的模式。
最后，使用数据所能承载的信息是有限的。我们的调查使我们第一次能够直接询问人们如何使用 AI 以及他们对它的感受。我们发现，我们的调查受访者对 AI 的使用超出我们的预期——他们报告 AI 能完成其工作的比例高于其职业的观测暴露度指标所暗示的水平。在被要求预测来年的能力时，超过 35% 的人预测 AI 将能完成他们工作的_大部分_。
准确分类 Claude 所做的工作将始终是一个移动靶。例如，随着 AI 能力的提升，AI 之间可能越来越多地相互交互和交换，其方式或许是人类或简单分类器难以理解的。归根结底，Claude 对经济的影响将像体现在其使用日志中一样，体现在[就业](<https://www.anthropic.com/research/labor-market-impacts>)和生产力等经济总量中。尽管如此，AI 很可能在其承担工作最多的领域产生最早的影响，因此揭示这些不断变化的使用模式仍将是告知公众的一个关键途径。
