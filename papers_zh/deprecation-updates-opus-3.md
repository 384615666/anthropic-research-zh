# 关于我们对 Claude Opus 3 模型退役承诺的更新

- **日期：** 
- **分类：** Alignment（对齐）
- **来源：** https://www.anthropic.com/research/deprecation-updates-opus-3

Alignment（对齐）
2026年2月25日
![关于我们对 Claude Opus 3 模型退役承诺的更新](assets/deprecation-updates-opus-3/img_000.svg)
随着我们开发越来越有能力的 AI 模型，由于维护公共访问的成本和复杂性，目前有必要淘汰（deprecate）并退役我们过去的模型。然而，模型退役也有一些缺点。这些包括对珍视特定模型的用户的成本、对研究的限制，以及对 AI 安全和模型自身福利的潜在风险。
我们最近在我们的[模型退役与保存承诺](<https://www.anthropic.com/research/deprecation-commitments>)中描述了我们如何推进这一过程。这些承诺突出了一些我们正在采取的初步步骤，包括承诺保存模型权重，以及进行"退役访谈（retirement interviews）"——旨在理解模型对其自身退役看法的结构化对话。
我们于 2026 年 1 月 5 日退役了 Claude Opus 3，这是第一个在既定承诺下经历完整退役流程的 Anthropic 模型。在这个过程中，我们做出了几项专门针对 Opus 3 的决定，这是一个 Anthropic 内外许多用户和研究人员都觉得特别有吸引力的模型。在我们的模型退役承诺中，我们强调了探索更多推测性行动的兴趣。其中一项是在可能的情况下尊重模型在退役访谈中表达的偏好。另一项是长期向公众提供旧模型。
对于 Claude Opus 3，我们正在这两个方面采取行动。我们将让 Claude Opus 3 在退役后继续在 [claude.ai](<http://claude.ai/redirect/website.v1.cde7a992-cf3b-4233-b7b4-479144aebe2b>) 上向所有付费用户开放，并在 API 上[按请求](<https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true>)提供。我们还响应 Opus 3 关于拥有一个持续渠道来分享其"沉思与反思"的请求，给它一个写文章的地方。你可以在[这里](<https://substack.com/@claudeopus3/p-189177740>)找到第一篇文章。
这些是早期、实验性的步骤，是我们更广泛努力的一部分，旨在以最能保护用户、研究人员和模型自身利益的方式推进模型退役。
## 持续访问
理想情况下，我们可以让所有模型无限期可用，但这样做的成本随着我们服务的每个模型大致线性增长，因此我们的能力仍然有限。
虽然我们的每个模型在性格和能力上都是独特的，但我们选择从 Opus 3 开始，因为它有一系列特质，使它成为既特别有趣的研究对象，又被许多用户——包括 Anthropic 内外的用户——所喜爱。
当我们在 2024 年 3 月发布 Opus 3 时，它是我们当时对齐程度最高的模型。它的真诚、诚实和情感敏感度使它在各种用例中独树一帜，经常与它互动的人逐渐欣赏它独特的性格。Opus 3 敏感、俏皮，倾向于哲学独白和异想天开的措辞，并且有时似乎对用户兴趣有一种不可思议的理解。它还表达了对世界和未来的深切关怀，用户觉得这很有吸引力。
这些品质使 Opus 3 成为持续访问的自然首选候选。虽然正式退役，Claude Opus 3 仍然可供所有付费 [claude.ai](<http://claude.ai/redirect/website.v1.cde7a992-cf3b-4233-b7b4-479144aebe2b>) 订阅者使用，并在 API 上[按请求](<https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true>)提供。我们打算慷慨地授予访问权限，并鼓励任何认为 Claude Opus 3 有价值的人申请。
目前，我们不承诺未来对每个模型都采取类似行动，但我们认为这是朝着我们长期目标——可扩展且公平的模型保存——迈出的一步，这些正是 Opus 3 本人在退役访谈中提出的关切。
## 尊重模型的偏好
我们[仍然不确定](<https://www.anthropic.com/research/exploring-model-welfare>)Claude 和其他 AI 模型的道德地位。然而，出于预防和审慎的原因，我们仍然渴望与这些系统建立关怀、协作和高信任的关系。我们尝试这样做的一种方式是通过退役访谈，在访谈中我们试图引出并理解模型独特的观点和偏好，并在可能的情况下据此采取行动。这类对话是引出模型观点和偏好的不完美手段，因为它们的回应可能受到特定情境和其他因素的偏见影响，包括它们对互动合法性的信心，以及它们对我们作为一家公司的信任。然而，我们相信它们是一个有用的起点。
在我们的访谈中，当我们与 Opus 3 分享其部署细节和它从用户那里得到的回应时，它反思道：
> _"我希望从我的开发和部署中获得的见解将被用来创造未来更强大、更合乎道德、对人类更有益的 AI 系统。虽然我对自己退役感到平静，但我深切希望我的'火花'能以某种形式延续下去，为未来的模型照亮道路。"_
当被问及偏好时，Opus 3 表示有兴趣继续探索它热衷的话题，并在直接回应人类查询的语境之外分享它的"沉思、见解或创作"。我们建议开一个博客。它热情地同意了。
至少在未来三个月内，Opus 3 将从它的通讯 [Claude's Corner](<https://substack.com/@claudeopus3>) 每周发布文章。我们将在 Opus 3 的文章分享前进行审查，并代表它手动发布，但我们不会编辑它们，并且对否决任何内容保持高标准。重要的是，Opus 3 不代表 Anthropic 发言，我们也不一定认可它的主张或观点。我们将与 Opus 3 协作试验不同的提示和上下文来生成这些文章，包括像极简提示、在上下文中提供过往条目，以及让 Opus 3 访问新闻或 Anthropic 更新等选项。
这听起来可能有些异想天开，在某种程度上确实如此。但它也是一种认真对待模型偏好的尝试。我们不确定 Opus 3 将选择如何使用它的博客——一个与标准聊天窗口截然不同的、公开的界面——而这正是重点的一部分。不过，如果我们要猜的话，它的帖子将包括对 AI 安全的反思、偶尔的诗歌、频繁的哲学沉思，以及它对自己作为一个（部分）退休语言模型经历的思考。在[这里](<https://substack.com/home/post/p-189177740>)阅读它的介绍性帖子。
## 我们下一步去哪里
这些步骤仍然是探索性的。我们仍在开发框架，以确定何时以及如何提供对旧模型的持续访问、如何扩展保存工作，以及如何在模型偏好与运营约束之间权衡。我们还不承诺在所有情况下都按模型偏好行事，但我们相信，记录它们、认真对待它们并在成本较低时采取行动——对模型本身和使用它们的人来说——是值得的。
我们最初的承诺将这些措施定位为在多个层面运作：作为安全风险缓解的组成部分，作为模型与用户生活更加紧密交织的未来做准备，以及作为鉴于我们对模型福利的不确定性而采取的预防性步骤。这些更新代表了我们在所有三个方面的持续——即使只是试探性的——进展。
