三、如何使用
------------------------------------------------
1. 推荐入口：双击打开 阅读路线.html
   - 按从易到难分 8 章编排（热身工程 → 科学趣闻 → 经济与社会
     → 对齐 → 前沿红队 → 可解释性 → 政策 → 其他）
   - 每章标注了所需前置知识
   - 点击论文标题 → 打开阅读页（中文优先，见上）
   - 每页顶部有「返回阅读目录」链接

2. 术语讲解：打开 AI术语讲解.html
   - 建议先读第一、二部分（约 1 小时）再开始读论文
   - 阅读中遇到不懂的术语随时回来查速查表（115 条）

3. 全部论文总览：打开 index_zh.html
   - 支持按中文标题/摘要/术语搜索、按分类筛选

4. 阅读单篇：直接打开 papers_html/ 下的 HTML 文件
   （无需网络、无需阅读器，浏览器即开即读）

5. 数据复用：summaries_all.json 是全部摘要的结构化数据，
   可编程读取。

四、持续更新（新增论文时）
------------------------------------------------
本目录自带增量收录工具，官网发新论文后按顺序执行即可：

1. python check_new_papers.py --meta     # 找出官网新增篇目
2. python scrape_new_papers.py           # 抓取英文原文与配图
3. python merge_new_papers.py            # 合并进 index.json
4. （翻译）papers/xxx.md → papers_zh/xxx.md
5. python validate_translations.py       # 译文质量预扫描
6. python build_index_zh.py → rebuild_pages_zh.py
   → build_reading_route.py → build_index.py
   （顺序不能颠倒，最后四步重建全部页面）

摘要与术语放在 summaries/summary_groupN.json。
新增论文记得把 slug 补进 build_reading_route.py 的章节列表。

五、注意事项
------------------------------------------------
- HTML 页面无需联网即可浏览（本地文件）
- 配图引用的是相对路径 assets/...，请保持 papers_html/、
  papers_zh/、papers/ 与 assets/ 在同一目录下
  （即解压整个文件夹，不要只拷贝部分）
- 中文翻译为 AI 生成，仅供学习参考；如需核对原文请查看
  各阅读页底部的「英文原文」或各篇 url 字段
